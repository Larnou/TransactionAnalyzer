# TransactionAnalyzer


**🔍 Курсовая работа по работе с 
транзакциями**
---


## 🎯 Цель проекта
_"Создатиь удобный способ генерации разного рода отчётов и результатов по исследованию трназакций по набору данных."_


# 📦 Описание входящего файла
* **Дата операции** — _дата, когда произошла транзакция._
* **Дата платежа** — _дата, когда был произведен платеж._
* **Номер карты** — _последние 4 цифры номера карты._
* **Статус** — _статус операции (например, OK, FAILED)._
* **Сумма операции** — _сумма транзакции в оригинальной валюте._
* **Валюта операции** — _валюта, в которой была произведена транзакция._
* **Сумма платежа** — _сумма транзакции в валюте счета._
* **Валюта платежа** — _валюта счета._
* **Кешбэк** — _размер полученного кешбэка._
* **Категория** — _категория транзакции._
* **MCC** — _код категории транзакции (соответствует международной классификации)._
* **Описание** — _описание транзакции._
* **Бонусы (включая кешбэк)** — _количество полученных бонусов (включая кешбэк)._
* **Округление на «Инвесткопилку»** — _сумма, которая была округлена и переведена на «Инвесткопилку»._
* **Сумма операции с округлением** — _сумма транзакции, округленная до ближайшего целого числа._

## 🚀 Использование
**Для работы необходимо запустить желаемый модуль среди которых:
* reports.py
* services.py
* utils.py
* views.py

И запустить один из реализованных сценариев.**

Чтобы понимать, как работают функции в виджете, 
для каждого описан docstring. Ниже можно найти полный список всех реализованных функций, 
разбитых по модулям

**Функции**

* Модуль reports
  * `write_log_to_file()` — Записывает данные data_log в файл по пути filename.
  * `log()` — Декоратор, позволяющий проанализировать и отследить поведение функции.
  * `spending_by_category()` — Возвращает траты по заданной категории за последние три месяца от переданной даты.

* Модуль services
  * `get_transaction_history()` — Получение списка транзакций по заданному ограничению по времени. 
  Период строится следующим образом:
    Выбирается месяц и год для анализа. После чего получается список всех транзакций за этот период.
  возвращает ее маску.
  * `service_cashback()` — Получение списка кешбеков по заданному ограничению по времени. Период строится следующим образом:
    Выбирается месяц и год для анализа. После чего получается список всех транзакций за этот период.
    И определяется кешбек.

* Модуль views
  * `main_view()` — Возвращает информацию по общим тратам, по каждой карте: последние 4 цифры карты; общая сумма расходов;
    кешбэк (1 рубль на каждые 100 рублей), топ-5 транзакций по сумме платежа, курс валют, стоимость акций из S&P500.
  * `main_event()` — Возвращает информацию по общим тратам, по категориям, информацию о поступлениях по категориям, курс валют,
    стоимость акций из S&P500.

* Модуль masks
  * `get_mask_card_number()` — Функция get_mask_card_number принимает на 
  вход номер карты и возвращает ее маску. Номер карты замаскирован и отображается 
  в формате XXXX XX** **** XXXX, где X — это цифра номера.
  * `get_mask_account()` — Функция get_mask_account принимает на вход номер 
  счета и возвращает его маску. Номер счета замаскирован и отображается в 
  формате **XXXX, где X — это цифра номера.

* Модуль utils
  * `create_logger()` — Создание именованного логгера с записью в указанный файл.
    Автоматически создает директорию для логов, если она не существует.
  * `get_welcome_words()` — Возвращает приветственные слова в зависимости от времени пользователя.
  * `get_transaction_history()` — Получение списка транзакций по заданному ограничению по времени. Период строится следующим образом:
    Если дата — 20.05.2020, то данные для анализа будут в диапазоне 01.05.2020-20.05.2020.
  * `get_card_numbers()` - Получение списка номеров карт, с которых выполнялись платежи.
  * `get_transactions_by_card_number()` — Получение списка транзакций с определённой в card_number номера карточки.
  * `get_card_transactions_info()` — информациии по списку транзакций card_transactions, совершённых с номера карты card_number.
    Информация включает в себя: сведения о номере карты, сколько было потрачено средств (прибыль - траты),
    количество кешбека, которое можно получить за эти операции.
  * `get_cards_transactions_info()` — Получение информациии по списку транзакций card_transactions, совершённых с номеров карт card_numbers.
  * `get_top_transactions()` — Получение информациии по списку транзакций с самой большой суммой платежа. Информация включает в себя сведения:
    дата платежа, сумма операции, категория операции и описание этой операции.
  * `get_currency_rates()` — Получение информациии текущему курсу валют из currency_list.
  * `get_usd_rate()` — Получение информациии текущему курсу USD.
  * `get_stock_prices()` — Получение информациии текущему курсу акций из stock_list.
  * `get_date_range()` — Возвращает диапазон дат на основе входной даты и типа диапазона.
  * `get_transaction_history_ranged()` — Получение списка транзакций по заданному ограничению по времени. Период строится следующим образом:
    Если дата — 20.05.2020, то данные для анализа будут в диапазоне 01.05.2020-20.05.2020.
  * `get_total_expenses_amount()` — Получение общего значения расходов за указанный список транзакций.
  * `get_total_income_amount()` — Получение общего значения пополнений за указанный список транзакций.
  * `get_categories()` — Получение списка категорий, с которых выполнялись платежи.
  * `get_amount_by_category()` — Получение сумм расходов по категории category из списка transaction_data.
  * `get_expenses_by_top_categories()` — Получение сумм расходов по 7 категориям с самыми большими тратами.
  * `get_transfers_and_cash()` — Получение сумм расходов по переводам и пополнениям с убванием по сумме.
  * `get_income_categories()` — Получение сумм поступлений по категориям с убванием по сумме.
